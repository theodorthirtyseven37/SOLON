## Bugs found & fixed

### Fixed (in `product/solon-local` branch)
1. **`cx22` deprecated** → changed to `cx23`
2. **`fsn1` disabled** → changed to `nbg1`
3. **`solon --config` doesn't exist** → changed to `solon serve`
4. **No SSH access** on provisioned servers → inject SSH keys from Hetzner account
5. **Replay attack** possible on provisioner callback → added timestamp validation (5-min window)
6. **API key extraction failure silent** → now fails provisioning explicitly
7. **Shell injection** possible via server name → sanitize input
8. **Dashboard 401 behind reverse proxy** → API key login screen + Bearer auth
9. **D1 migrations not applied** → `managed_instances` table created manually
